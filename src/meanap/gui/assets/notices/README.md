# Update notices

Each `.md` file here (other than this one) is shown once, in a "What's new"
window, to people who update past its `version`. See `meanap/gui/whats_new.py`.

Use them only for changes people must know about to read their results
correctly, such as a new default. Format:

    ---
    version: 1.40.0
    title: One line saying what changed
    link: https://analysis-pipeline.readthedocs.io/en/latest/news/<post>.html
    ---
    A few short paragraphs: what changed, why, what to do to keep the old
    behaviour.
