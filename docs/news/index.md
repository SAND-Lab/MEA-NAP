# News

What's new in MEA-NAP, newest first.

<!-- news:start -->

## [A simpler MEA-NAP: the new default view](2026-11-19-simple-view.md)

*19 November 2026*

A redesigned interface for running MEA-NAP and viewing its results, with a step-by-step setup, a search bar and a new results viewer.

## [MEA-NAP now runs faster](2026-11-19-express-mode.md)

*19 November 2026*

MEA-NAP now uses express mode by default. A run's analyses are saved to a single .meanap file, and you view the plots in the MEA-NAP GUI.

## [MEA-NAP in Python: beta release](2026-10-20-python-beta.md)

*20 October 2026*

MEA-NAP is now available in Python (beta). It is much faster and adds a lot of new features; the MATLAB version is still supported.
